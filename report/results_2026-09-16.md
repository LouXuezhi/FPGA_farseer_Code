# 阶段结果（2026-09-16）

T1（公开温度散斑数据集 → 板上定点推理）已打通：训练、量化、Verilog 推理核、两条通信链路、主机收发程序、综合实现全部完成，尚未上板实测。

## 1. 精度

数据集 OSF 8nxvk（14 组实验 × 1752 张）。**dataset 14 全程不参与训练和选型**，只在最后评估一次；模型与超参只按验证集选择。

| 模型 | 参数量 | 内部测试 RMSE | **D14 RMSE** | D14 MAE |
|---|---|---|---|---|
| MNet-reg 浮点（复现 Photonics 2026） | 640 万 | 0.97 | 1.73 ± 0.02（3 seed） | 1.35 |
| QCNN 定点（板上实际运行） | 6.1 万 | 1.66 | **2.12** | 1.70 |
| 论文 Photonics 2026 Model 3 | 640 万 | — | 0.90 | 0.69 |

- 论文数字含 95% 置信区间离群过滤；按同一口径我们的 MNet-reg 为 MAE 1.22。
- 论文数据缩放趋势可复现：训练用 1 组 / 6 组 / 13 组数据时 D14 RMSE 分别为 15.3 / 11.2 / 1.73。
- QCNN 量化方案：权重 int8、激活 12 bit 无符号、缩放因子取 2 的幂（重量化只需移位）。8 bit 激活会额外损失约 0.6 °C。

## 2. 推理核（src/rtl/qcnn）

```
loader ─► conv0 ─► conv1 ─► conv2 ─► conv3 ─► head
56²×1     28²×16   14²×32   7²×64    4²×64    GAP → FC64→16 → FC16→1
```

输出通道按 `PAR` 路并行：固定输出像素和卷积核位置时所有输出通道共享同一个输入激活，因此每周期只读一次源 RAM 就能喂满 `PAR` 个乘法器。conv0 用 8 路，conv1–conv3 各 32 路。

| | 串行（1 乘法器/层） | 并行（PAR） |
|---|---|---|
| 稳态每帧 | 18.06 ms（55 fps） | **0.565 ms（1770 fps）** |
| 首帧延迟 | 25.1 ms | 0.94 ms |

## 5. 三个踩过的坑

1. **综合忽略 `initial` 块里的非常量赋值**：权重 ROM 的分片循环在仿真里正常、综合时被丢弃，生成的比特流权重全是 0，而时序和资源报告看不出任何异常。改为 Python 侧按 lane 导出 `.mem` 文件。
2. **偏置 ROM 地址位宽**：`bias_rom[s2_g_q*PAR+p]` 按 8 位计数器推断成 8192 深，每路占一块 BRAM，BRAM 一度用到 139/140。改用按 `C_OUT` 的精确位宽。
3. **门级仿真的全局复位（GSR）**：前 100 ns 所有触发器被强制复位，testbench 若在此期间就开始发数据，握手信号看起来正常但数据会被丢弃。复位要保持到 GSR 释放之后。

前两个都是"仿真通过、上板错误"的类型，因此把综合后功能仿真固定进流程（`sim/rtl/run_postsynth.sh`、`run_xsim_layer.sh`、`run_xsim_head.sh`）。
