# 02 RTL 仿真通过、综合后权重全为 0

会话：QCNN 推理核前期验证（单帧形状）

## 提示词（整理）

> `tb_conv_layer` 在 RTL 下和参考模型逐位一致，换成综合后网表（`run_xsim_layer.sh 0 postsynth`）后输出全是偏置值，
> 像是权重全为 0。时序报告满足，资源报告里 BRAM 数量也正常。权重 ROM 是在 `initial` 块里按 lane 从一个大数组切出来的。
> 请只依据这些信息判断原因，并给出能确认的检查。

## 模型回答（摘要）

- Vivado 综合只接受 `initial` 块里的常量赋值和 `$readmemh`；在循环里按参数计算下标去填存储器属于非常量初始化，会被忽略并当作全 0。
  RTL 仿真器会执行 `initial` 块，所以 RTL 仿真看不出问题。
- 检查：综合日志搜 `initial` 相关的 WARNING；或在综合后网表里查该 ROM 的 `INIT_xx` 属性是否全 0。

## 纠错

`initial` 块里的切片是助手自己写的，RTL 仿真通过后助手按"存储器初始化必须跑综合后网表"的检查补跑了网表仿真，才暴露问题。
修复是让 Python 参考模型直接按 lane 导出 `.mem` 文件，RTL 只用 `$readmemh` 读文件，存储器内容与硬件结构分开。

## 结果

综合后网表与参考模型逐位一致。这次之后参考模型（`src/model/qcnn_int.py`）成为权重、移位参数和测试向量的唯一来源，
换模型只需重新导出，RTL 不改。当前训练权重下推理核 144/144 逐位一致（`sim/results/tb_qcnn_core.log`）。
