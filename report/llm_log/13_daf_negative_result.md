# 13 数字孔径滤波（DAF）预处理：小批量试验给出否定结论

会话：在远端训练机已有采集数据上，试 DAF 预处理 + CNN 是否改善温度回归　日期：2026-11-02

## 提示词（整理）
> 远端有采集数据，试试先做数字孔径滤波（DAF）预处理，再用 CNN 看结果。小批量试试有没有效果。

## 模型回答（摘要）
- 先确认相机拍到的是近场还是远场光斑，因为两种情况下 DAF 的实现不同。
- 实现两种 DAF：频域光瞳（强度开方近似振幅，FFT 后保留 0.7 或 0.5 倍原光瞳半径）和空间孔径（只保留中心圆形区域）。
- 6 个 ramp session 训练、2 个固定 session 验证，训练设置与当前流水线默认一致（2 epoch）。
- 另设两个对照：blank（图像全部置 0）和全零预测。
- 实验脚本单独放在新目录，不改另一个会话正在修改的 `pipeline.py` 和模型版本库。

## 纠错
无明显纠错。这段的价值在于模型主动加了"图像全 0"的对照组，用它把问题从"DAF 有没有用"推进到"CNN 有没有从图像学到东西"：

| 变体 | 参考点 + 残差 | 只用图像 |
|---|---|---|
| 不滤波 | 0.0584 | 0.0808 |
| 频域光瞳 0.7 | 0.0585 | 0.0811 |
| 频域光瞳 0.5 | 0.0584 | 0.0807 |
| 空间孔径 0.6 | 0.0582 | 0.0807 |
| blank（图像全 0） | 0.0585 | 0.0811 |

（指标：验证集去噪标签 MAE）

- 模型同时说明证据强度有限：每个变体只跑 1～2 个 seed，论文全文要付费、只看到摘要，孔径参数按原理自定。所以结论写成"没有明显效果"，不写"定死无效"。

## 结果
- DAF 各变体与不滤波相比差异在 ±0.0003 以内，与图像全 0 的对照持平。
- 不训练的检查：帧对去相关 1−corr 与 |ΔT| 的秩相关在 DAF 后没有升高（只用图像组 0.396 → 0.386～0.391）。
- 解释：论文针对的是高阶模让散斑去相关过快；本数据 3～10 s 帧对的去相关只有 0.2～0.3，瓶颈不在这里。
- 后续方向转为先查清"图像为什么对 ΔT 没有贡献"，引出激光慢漂移专题（见 14）。
