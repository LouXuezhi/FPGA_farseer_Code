# 工具链核查（2026-09-15）

| 项 | 现状 | 影响 / 处理 |
|---|---|---|
| Vivado | 本机 `/opt/xilinx/2025.1`，ML Standard，已装 Zynq-7000/Artix-7/Spartan-7；**未装 Zynq US+** | 赛事推荐 2026.1 或 2025.2，使用 2025.1 需在报告说明并保证脚本可复现；是否升级待定 |
| FINN（refs/finn） | 需要 Vivado/Vitis 2024.2+；**自 2024.2 起 Pynq-Z1/Z2 退出官方支持**（`src/finn/util/basic.py` 中 `retired_pynq_boards`），可手动移除该集合并恢复 `fetch-repos.sh` 中板卡文件下载；官方推荐替代板 AUP-ZU3 | FINN 用于 PYNQ-Z2 属于"可用但无保证" |
| hls4ml（refs/hls4ml） | `vivado_accelerator` 后端自带 `pynq-z2` 模板（AXI-Lite / AXI-Stream） | **小 MLP / 1D-CNN 优先用 hls4ml**；FINN 作为备选 |
| pyMMF（refs/pyMMF） | `IndexProfile.initStepIndex(n1, a, NA)`、`propagationModeSolver.solve(...)`、`modes.betas`、`modes.getModeMatrix()`；示例 `docs/examples/Benchmark_SI.ipynb` | D1 合成使用 |
| PYNQ（refs/PYNQ） | 源码参考 | SD 镜像需手动下载（见下） |

## 需要手动下载 / 登录的

- PYNQ-Z2 SD 卡镜像（v3.x）：https://www.pynq.io/boards.html
- Vivado/Vitis 2025.2（若决定升级）：https://www.xilinx.com/support/download.html （需 AMD 账号）
- XADC 用户指南 UG480：https://docs.amd.com/v/u/en-US/ug480_7Series_XADC
- PYNQ-Z2 用户手册：https://www.tulembedded.com/FPGA/ProductsPYNQ-Z2.html
